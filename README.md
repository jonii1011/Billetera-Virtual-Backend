#AlkyWallet - Billetera Virtual 💰


AlkyWallet es una aplicación de billetera virtual desarrollada como proyecto final del curso de Aceleracion Tech de Alkemy y Innovación Tierra del Fuego. Esta solución permite a los usuarios gestionar sus finanzas digitales de manera segura y eficiente.

🚀 Características Principales
Gestión de Usuarios: Registro, autenticación y administración completa de perfiles de usuario
Transacciones Seguras: Envío y recepción de dinero entre usuarios registrados
Historial de Movimientos: Seguimiento detallado de todas las transacciones realizadas
Gestión de Saldo: Consulta de saldo actual y movimientos de cuenta
Panel de Administración: Herramientas para la gestión y supervisión del sistema
API RESTful: Interfaz de programación robusta y bien documentada
🛠️ Tecnologías Utilizadas
Backend
Java 17+
Spring Boot 3.x
Spring Security - Autenticación y autorización
Spring Data JPA - Persistencia de datos
MySQL/PostgreSQL - Base de datos
Maven - Gestión de dependencias
Swagger/OpenAPI - Documentación de API
Herramientas de Desarrollo
Git - Control de versiones
Postman - Testing de API
📋 Pre requisitos
Java 17 o superior
Maven 3.6+
MySQL 8.0+ o PostgreSQL 12+
Git
